# 数值门突击 · 抖音特效版

> **这是 [gate-runner](https://github.com/dsjsunu/gate-runner) 3D 网页版的抖音「像塑」（Xiangsu）移植版。**
> 玩法同源，但表现和完成度**不如网页版** —— 网页版是主版本，这里只作为特效侧的实现留档。

触屏左右控制的数值门跑酷：三波门、固定战损、Boss 光束。

## 和网页版的区别

| | [3D 网页版](https://github.com/dsjsunu/gate-runner)（主版本） | 抖音特效版（本仓库） |
|---|---|---|
| 引擎 | Three.js | 像塑 APJS |
| 运行平台 | 浏览器 | 抖音特效 |
| 人数上限 | 300 | **24** |
| 人群渲染 | InstancedMesh，全场景 8 个 draw call | 每个小兵一个 Prefab 节点 |
| 兵种模型 | 程序化拼的几何体 | glb 预制体（身体 + 腿分件） |
| 控制 | 拖拽 / 键盘 | 触屏 |
| 关卡 | 4 组门 + 精英 + 首领 | **3 波**，只有数值门（含复合门） |
| 整备（花兵力换强化） | 有 | 无 |
| 动画 / 音效 | 完整跑动、合成音效 | 基础 |
| 完成度 | 高 | 中（手机实机未验收） |

人数上限掉到 24，是因为像塑没有 GPU 实例化，只能每个单位克隆一个节点。

## 玩法

- 每局开拍时等概率抽一套「三波门组合」（共 12 套），左右再随机交换
- 门包含 `+` `-` `×` `÷`（向下取整），以及有明确顺序的复合门：`+6 再 ÷2`、`×2 再 -3`、`+3 再 ×2`
- 第一波、第二波各固定损失 2 人
- Boss 固定 12 发、每发带走 1 人：**13 人以上必能剩兵反击，12 人及以下耗尽**
- 普通兵首次反击 0.72 秒，Boss 1.15 秒
- 第一波无震动，第 2/3 波震动带 1.2 秒冷却
- 结算按剩余人数分 1—5 星，共 24 种称号

### 难度不是抽胜负

起始 5 人，12 套组合里 **6 套的最优路径能通关、6 套不能**（16/10/11、10/7/7、7/11/12、8/9/11、5/7/10、5/5/10 这六套失败）。是固定算术 + 固定战损自然形成的 50%，不是随机判死。

## 工程

像塑工程，用像塑编辑器打开 `effect.dyehpj`。

```
Assets/
  Scripts/GateRunner.ts   玩法脚本（3D 网格 + 2D HUD）
  *.glb                   小兵 / 精英 / Boss 的身体与腿
  *.png / *.mp3           贴图与音效
EffectSettings/           特效参数
EventChains/              事件链
Graph/                    节点图
effect.dyehpj             工程文件
DESIGN.md                 完整设计稿
```

`Library/`（编辑器缓存）和 `.mcp_agent/`（运行日志）已在 `.gitignore` 中排除。

### 遗留资源

本工程是从 `portal-marble` 派生的，`Assets/` 里还留着银河弹珠和击剑特效的贴图（银河机台、星钉、灯道等）以及 `MarbleGame.ts`、`FencingGame.ts`。这些目前没有被 GateRunner 使用，但场景里可能仍有引用，所以没有删除。后续可以清理，大约能省 10 MB 以上。
